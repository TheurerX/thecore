## Обзор проекта

**TheCore** — компактная утилита для мониторинга железа и обслуживания Windows.

Программа построена по принципу **Offline-First & Zero-Telemetry**: в ней нет сетевых запросов, трекеров и аналитики. Интерфейс выполнен в современном бесшовном темном стиле с полным отсутствием искусственных обводок (`border: none`).

---

## Ключевые возможности

### Аппаратный мониторинг в реальном времени
* **Процессор (CPU):** Поточечная нагрузка ядер, архитектура, сокет и расчет энергопотребления.
* **Видеокарта (GPU):** Прямая интеграция с NVIDIA NVML (`pynvml`) и WMI: температуры чипа и памяти, частоты, обороты вентиляторов и ваттметр.
* **Оперативная память и Накопители:** Мониторинг частоты RAM с проверкой заводского профиля XMP в чипе SPD, состояние дисков NVMe/SATA, занятое пространство и температуры.
* **Расчет Блока Питания (БП):** Динамический расчет потребления системы под пиковой нагрузкой с учетом запаса под броски тока.
* **Индекс производительности Windows (WEI):** Возрождение оценки 1.0–9.9 из Windows 7 по 5 аппаратным направлениям с выявлением узкого места системы.

### Оптимизация системы
* **Экспресс-аудит:** Мгновенный предварительный расчет потенциала очистки памяти, файлов `%TEMP%`, кэша шейдеров и фоновых клиентов без изменения файлов.
* **Сброс рабочего набора RAM (`EmptyWorkingSet`):** Освобождение зарезервированной памяти через нативный Win32 API без риска краша приложений.
* **Очистка кэша шейдеров GPU:** Безопасное удаление накопившихся временных файлов компиляции шейдеров DirectX (DXCache), Vulkan (GLCache), NVIDIA и AMD.
* **Выгрузка фоновых апдейтеров:** Закрытие тяжелых лаунчеров (Steam, Epic Games, Discord, Telegram, торрент-клиентов) с белым списком критических системных процессов.

### Управление автозагрузкой Windows
* Сканирование реестра (`HKCU`, `HKLM`, `shell:startup`, `StartupApproved\Run`).
* Фильтрация фантомных записей — отображение только реально активных программ с оценкой их влияния на старт ПК.
* Постоянная карточка TheCore для управления автозапуском в системный трей (`--hidden`).

### Интеллектуальный «Советник по апгрейду»
* Детерминированное экспертное дерево правил подбора железа (сокет, поколение CPU, видеокарта, двухканальный режим).
* Поиск отключенного XMP/DOCP в SPD памяти (карточка ускорения на 0 руб.).

### Игровой оверлей (HUD)
* Прозрачный виджет поверх игр с отображением FPS, нагрузки CPU/GPU и температур.
* Архитектура Zero-Ban: оверлей работает через прозрачное окно Windows со сквозным кликом, без инъекций DLL в память игры.
* Включение и выключение по комбинации `Ctrl+Shift+O`.

## Архитектура и безопасность

* **IPC-канал:** Динамическое рукопожатие HMAC-SHA256 с ротацией одноразовой соли между Electron и ядром Python.
* **Антиотладка:** Аппаратные проверки Win32 `IsDebuggerPresent` и `CheckRemoteDebuggerPresent`.
* **Zero-Telemetry:** Полная автономность — программа не отправляет ни одного байта в сеть.

## Установка

Готовые установочные файлы доступны на [странице релизов](https://github.com/TheurerX/thecore/releases/latest).

1. Скачайте инсталлятор **`TheCore.exe`**.
2. Запустите установку.
3. Приложение готово к работе.

---

## Сборка из исходников

```powershell
# Клонирование репозитория
git clone https://github.com/TheurerX/thecore.git
cd thecore

# Установка зависимостей
npm install

# Запуск в режиме разработки
npm start

# Сборка готового защищенного инсталлятора
npm run build
```
