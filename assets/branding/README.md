# TheCore — Брендбук и спецификация айдентики (v3.2.0)

> **Автор:** Theurer (Тойрер)  
> **Смысл названия:** `The` (авторская подпись) + `Core` (кремниевое процессорное ядро, аппаратная телеметрия и оптимизация).  
> **Дизайн-система:** Seamless Halftone Liquid Glass (`border: none !important`).

---

## 1. Концепция логотипа: «Silicon Core: High-Contrast Quad»

Векторный знак представляет собой монолитный кремниевый кристалл процессора, окруженный 4 орбитальными сегментами аппаратной телеметрии ПК:

```text
       [ CPU ] 🔶         🟢 [ GPU ]
          (Янтарь)          (Изумруд)
                  \       /
                 [ TheCore ]  <-- Центральный обсидиановый кристалл
                  /       \
          (Фиолет)          (Коралл-Роза)
       [  RAM  ] 🟣         🔴 [ Displays / PSU ]
```

### Цветовые градиенты узлов:
1. **Процессор / CPU (Верхний левый сектор):**
   * Градиент: `#FBBF24` (Золотой янтарь) $\rightarrow$ `#D97706` (Глубокий янтарь)
2. **Видеокарта / GPU (Верхний правый сектор):**
   * Градиент: `#10B981` (Неоновый изумруд) $\rightarrow$ `#047857` (Хвойный изумруд)
3. **Дисплеи и Питание / Displays & PSU (Нижний правый сектор):**
   * Градиент: `#FB7185` (Светлая коралл-роза) $\rightarrow$ `#E11D48` (Насыщенная роза)
4. **Оперативная память / RAM (Нижний левый сектор):**
   * Градиент: `#A78BFA` (Лавандовый фиолет) $\rightarrow$ `#6D28D9` (Королевский фиолет)
5. **Центральный чип / Silicon Die:**
   * Подложка: `#334155` $\rightarrow$ `#0F172A` (Сланцевый обсидиан)
   * Кристалл-диод: `#38BDF8` (Электрический циан)
